# Zephyrus для Android

Zephyrus — это современный медиа-загрузчик для Android на базе **yt-dlp** и **FFmpeg**, выполненный в стиле Material You (Material 3). Приложение является мобильной версией настольного [Zephyrus](https://github.com/RonovaMain/Zephyrus) и предлагает тот же интерфейс, вкладки и философию удобства в использовании.

## Возможности

* **Широкая поддержка источников:** Скачивание видео и аудио с сотен сайтов, поддерживаемых движком yt-dlp.
* **Гибкие форматы:** Видео (MP4, MKV, WEBM) и аудио (MP3, M4A, OPUS, FLAC, WAV).
* **Управление качеством:** Автоматический выбор лучшего качества или ручной выбор (раздельный выбор видео- и аудиопотоков с последующей склейкой через FFmpeg).
* **Информативный предпросмотр:** Отображение обложки, названия, автора и длительности медиафайла до начала загрузки.
* **Продвинутый менеджер загрузок:** Поддержка скачивания плейлистов целиком, полноценная очередь, возможность отмены и отображение прогресса в реальном времени (процент, скорость, оставшееся время, размер).
* **Фоновая работа:** Работа через службу переднего плана (Foreground Service) с управлением через уведомление.
* **Интеграция в систему:** Быстрая отправка ссылок в приложение через системное меню «Поделиться» из браузеров, YouTube и других клиентов.
* **Управление сессиями:** Вход в аккаунты через встроенный браузер для скачивания приватного или возрастного контента. Поддержка нескольких профилей на один сайт с безопасным шифрованием ключом из Android Keystore, а также импорт внешних файлов `cookies.txt`.
* **Умная история:** Полноценный поиск по загрузкам. Если файл был удален из памяти устройства, запись в истории бледнеет и предлагает кнопку «Скачать повторно».
* **Дополнительные функции:** Встраивание обложек, метаданных и субтитров, поддержка SponsorBlock, ограничение скорости и работа через прокси.
* **Интерфейс Material 3:** Динамические цвета на основе обоев (для Android 12+), светлая, тёмная и системная темы, а также 5 встроенных цветовых палитр (включая фирменную «Сакуру»).
* **Автономность:** Обновление движка yt-dlp одной кнопкой прямо из настроек. Приложение сохраняет файлы в публичную папку `Загрузки/Zephyrus` и не требует избыточных разрешений на доступ к хранилищу.

## Установка

1. Перейдите в раздел **Releases** данного репозитория.
2. Скачайте APK-файл, соответствующий архитектуре вашего устройства. Если вы не уверены, используйте универсальную сборку: `Zephyrus-<версия>-universal.apk`.
   * `arm64-v8a` — большинство современных смартфонов и планшетов.
   * `armeabi-v7a` — старые 32-битные устройства.
   * `x86_64` / `x86` — эмуляторы для ПК.
3. Откройте скачанный файл и разрешите установку приложений из используемого источника.

**Системные требования:** Android 10 (API 29) или новее.

## Известные ограничения

* **Авторизация через Google:** Встроенный компонент Android WebView может блокировать попытки входа в аккаунты Google (YouTube) из соображений безопасности. В качестве альтернативного решения используйте экспорт файла `cookies.txt` через сторонние браузерные расширения на ПК/смартфоне с последующим нажатием кнопки «Импорт cookies.txt» в приложении.
* **Чтение Cookies:** Из-за ограничений безопасности Android, WebView не предоставляет возможность сквозного чтения всех куки-файлов. Приложение запрашивает их только для базовых, известных доменов. Для специфических или региональных сайтов рекомендуется использовать ручной импорт `cookies.txt`.
* **Локализация:** На текущий момент интерфейс приложения доступен на русском языке.
